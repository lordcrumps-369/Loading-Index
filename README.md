# Loading-Index
This indexes the downloads folder, leading to faster load times in theory!

## Download Link
http://www.simfileshare.net/download/6352485/

## Known Issues
Some users have reported that this flags as a Trojan on their antivirus, therefore it is not being applied.
As you can see from the code it is not a Trojan, its just where it stops the game from checking millions of packages down to a fair few thousand so some anti-virus programs thinks it is because of the huge differences in how it reads.
